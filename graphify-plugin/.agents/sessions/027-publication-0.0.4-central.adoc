== Contrainte découverte — version dérivée du catalogue

L'EPIC MEM-CAT-ROLLOUT-6 (S-214/S-215) a câblé la version propre des boroughs
sur le catalogue workspace publié :

[source,kotlin]
----
version = ws.versions.graphify.plugin.get()
----

`Settings.gradle.kts` épinglait `workspace-catalog:0.0.33`, qui portait
`graphify-plugin = 0.0.3`. Publier 0.0.4 exigeait donc *d'abord* un bump du
catalogue MEMPHIS — c'est le pattern de la chaîne release documenté dans
`.agents/RELEASE_PROTOCOL.adoc` (MEMPHIS).

La garde `GraphifyPluginPublicationTest` (hygiène D5) impose de plus que le
toml local et le toml central s'accordent — le bump est donc vérifié.

depuis `agent-contracts/` a révélé une *baseline rouge à HEAD* (2 gardes
périmées, jamais réalignées) :

[cols="2,3", options="header"]

fait qu'elle n'ait pas été détectée indique que `contracts.catalog.*` n'est pas
systématiquement lancé en fin de session MEMPHIS.
