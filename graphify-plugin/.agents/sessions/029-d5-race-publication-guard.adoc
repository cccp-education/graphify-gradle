7 décisions. Doc `.agents/CADRAGE_EPIC_D5_RACE.adoc`.

*Décision de niveau* : pas de functional TestKit — l'artefact modifié est *la
garde elle-même* (un test) ; le niveau d'intégration est la gate `./gradlew test`
(le test JUnit s'exécute dans le build, alimenté par la propriété injectée).
Pattern S-024 documenté.

=== D5R-1 — Objets purs (source set `test`)

* `graphify.catalog.VersionCatalogToml` — lecteur minimal `[versions]`
  *scopé par section* : une clé hors `[versions]` ne peut jamais primer
  (essentiel : `graphify-plugin` et `graphify` existent aussi dans `[libraries]`
  / `[plugins]`). Gère commentaires (ligne entière, fin de ligne) et espaces.
* `graphify.catalog.PublicationHygiene` — verdict pur `consistent` + message
  (accord, drift, local manquant, publié manquant).
* 12 tests unit (`VersionCatalogTomlTest` 8 + `PublicationHygieneTest` 4).

Ces objets vivent dans `test/`, jamais dans le wire publié — ce sont des
utilitaires d'hygiène, pas du code d'extension `graph.json`.

=== D5R-2 — Wiring + refactor de la garde

* `build.gradle.kts` : `systemProperty("graphify.publishedCatalog.graphifyVersion",
  ws.versions.graphify.plugin.get())` — la version *publiée* résolue par Gradle
  est injectée dans la JVM de test.
* `GraphifyPluginPublicationTest` : suppression de `wsCatalogToml()` et de tout
  accès au repo voisin ; la garde lit la propriété injectée et s'appuie sur les
  objets purs. Absence de propriété → `error(...)` explicite, jamais un fallback
  silencieux.

*Preuve par l'absurde* (RED one-shot) : la propriété injectée est forcée à
`9.9.9` → le test de cohérence *échoue* ; restaurée → passe. La garde lit bien
la valeur publiée injectée, plus le working tree voisin.

`schema_version.feature`, pas de nouveau runner).
