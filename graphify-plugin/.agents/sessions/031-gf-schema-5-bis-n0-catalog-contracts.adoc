== GF-SCHEMA-5-bis — `schemaVersion` du graphe de corpus

* **Périmètre** : `ScanWorkspaceTask` produit `graph-content.json` en
  dogfooding ; la tolérance N0 (`@JsonIgnoreProperties` + `schemaVersion` par
  défaut) est livrée par `graphify-plugin 0.0.5` (GF-SCHEMA-5, S-028). Le risque
  initial est donc **caduque** : bakery et codebase importent
  `graphify.model.GraphModel` (pin `graphify = "0.0.5"`) et deviennent tolérants
  en bumpant, sans modifier une ligne.
* **Livré** : test end-to-end `ScanWorkspaceTaskTest.should stamp the schema
  version in the produced graph` — lit le JSON **brut** produit, vérifie
  `schemaVersion == GraphModel.SCHEMA_VERSION`, et charge un payload **legacy**
  (sans le champ) via le défaut partagé.
* **Dogfooding** : `graph-content.json` régénéré via le consumer
  (`./gradlew scanFpaCorpus` après `publishToMavenLocal` + alignement du
  consumer `graphify = 0.0.3 → 0.0.5`) → **1997 nœuds / 1871 arêtes** (vs 1989 /
  1857 en S-024), `schemaVersion: 1` en tête.
