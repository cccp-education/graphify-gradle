== Décisions architecturales

. *La tolérance vit dans la classe partagée (N0), pas chez chaque consommateur.*
   `@JsonIgnoreProperties(ignoreUnknown = true)` sur `graphify.model.GraphModel`.
   C'est la solution « cross-borough » la plus économe : bakery, codebase et
   tout futur consommateur deviennent tolérants *en bumpant leur dépendance*,
   sans modifier une ligne de leur code. L'annotation sur la classe l'emporte
   sur le `FAIL_ON_UNKNOWN_PROPERTIES = true` du mapper appelant.

. *`schemaVersion` = entier, porté par `GraphModel`.*
   `const val SCHEMA_VERSION = 1` dans le companion ; champ `schemaVersion: Int`
   avec valeur par défaut. Le défaut garantit qu'un `GraphModel()` construit en
   mémoire (tests consommateurs) reste valide sans changement.

. *Le défaut est le pont de rétrocompatibilité.*
   Un `graph.json` *legacy* (sans `schemaVersion`) se désérialise avec la valeur
   par défaut : zéro casse pour les fichiers existants.

. *Ordre de sûreté.* La tolérance et le champ sont livrés *ensemble* dans
   graphify, puis les consommateurs bumpent. Comme la tolérance est portée par
   la classe, un consommateur qui bumpe obtient les deux garanties d'un coup.

. *`graph.json` byte-identique entre deux runs* — la garde S-025
   (`SchemaFunctionalTest` déterminisme) reste en vigueur : `schemaVersion`
   est constant, donc le JSON reste stable.

. *English only* — code, commentaires, Gherkin.

. *Méthode* : baby-step DDD/TDD/BDD strict RED → GREEN → REFACTOR, 3 niveaux
   (unit → functional → cucumber), pattern établi S-025/S-026.

== Gates et risques

* *Non-régression bakery/codebase* : leurs tests (`SubgraphExtractorTest`,
  `GraphifyContextProviderTest`, `SubgraphWorld`) doivent rester VERTS après
  bump. Le défaut `schemaVersion` évite toute casse des constructions en
  mémoire ; l'annotation évite toute casse des lectures de fichier.
* *Garde de forme* : `SchemaFunctionalTest` doit être mise à jour *dans le même
  commit* que l'ajout du champ (sinon RED).
* *Dette de publication* : graphify 0.0.5 + MEMPHIS 0.0.45 = chaîne DAG
  (version dérivée du catalogue). Même protocole que S-027.
